# 📒 Trabajo Práctico Nº4 - Programación Orientada a Objetos (POO)

Este repositorio contiene los ejercicios realizados en el **TP Nº4 de POO**, implementados en **JavaScript** y organizados en distintos archivos (`01-auto.js`, `02-cuentaBancaria.js`, `03-rectángulos.js`, `04-productos.js`, `05-generaciones.js`, `06-libro.js`, `07-agenda.js`).

### 🚀 Funcionalidades principales
- Uso de **clases y objetos** para modelar distintos problemas.
- Ejercicios con **alert** y **prompt** para interacción con el usuario.
- Integración de la función `mostrarEnPantalla()` para mostrar resultados en consola y en el HTML.
- Ejemplo destacado: **Agenda Telefónica** con gestión de contactos (añadir, listar, buscar, eliminar, verificar si está llena y ver huecos libres).

### 🛠️ Tecnologías
- **JavaScript (ES6+)**
- **HTML5**
- **Bootstrap 5** (para estilos básicos)
